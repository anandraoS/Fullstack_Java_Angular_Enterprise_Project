# Risk Register - OMS

Scale: Likelihood (L) and Impact (I) are 1 (low) to 5 (high); Score = L x I. Review at each sprint review. Owners are roles, not named people. "Trigger" is the observable signal that the risk is materializing. Status column added and all rows re-checked against the code on 2026-10-18: all eight modules are implemented and integration-tested locally (H2 + embedded Kafka, no Docker); evidence in `docs/validation/`. Open items are linked to `docs/known-limitations.md`.
