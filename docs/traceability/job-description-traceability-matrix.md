# Job-description traceability matrix

Maps typical Senior Full Stack Java and Angular job requirements to what this repository actually implements. Evidence rules: **Executed** means a JUnit report, Playwright result or similar artefact exists on disk from a real run (the class and the test count are named); **Documented / not executed** means files exist (and may have been statically validated) but nothing was run; **Conceptual** means design discussion only. Every path in the source-code column is checked by `tools/pdf/check-refs.mjs`. Executed counts are from `target/surefire-reports` and `target/failsafe-reports` and from the live integration run (`docs/validation/validation-report.md`): reactor 968 cases, 939 executed, 0 failed, 29 skipped (all Docker/Postgres/benchmark), plus 2 retention tests added afterwards; Angular frontend 149/149; React frontend 207/207 (2026-10-19); live end-to-end 18/18 for each of the two UIs; smoke 10/10; API flows 54/54; oversell burst 3 FULFILLED and 27 REJECTED. The PDF evidence table regenerates the per-module counts at build time.
